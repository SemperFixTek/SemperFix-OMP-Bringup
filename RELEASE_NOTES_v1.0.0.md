# SemperFix OMP Bring-Up Package v1.0.0

## Summary
This is the first official SemperFix Package, providing a deterministic, repo-backed installation workflow for Oh-My-Posh across MASTERZERO, SECONDARY, and OFFSITE.

## Highlights
- Manual Oh-My-Posh binary installation
- JetBrainsMono Nerd Font standardization (Delugia deprecated upstream)
- Paradox theme standardization (SemperFix Standard)
- WindowsApps shadowing mitigation
- PowerShell profile auto-configuration
- Multi-machine repeatability
- PDF bring-up card included
- Full version metadata baked into installer and manifest
